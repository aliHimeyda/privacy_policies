## 1. Introduction

BOLT1 is a desktop productivity application designed to help users organize and launch frequently used web pages and desktop applications from a single interface.

The purpose of BOLT1 is to simplify the daily workflow of users by allowing them to create project-based workspaces, save web links and application shortcuts, and launch them later with a single action.

This Privacy Policy explains what information the application uses, how that information is handled, where it is stored, and what choices users have regarding their data.

BOLT1 is designed as a local desktop application. It does not provide user accounts, cloud synchronization, online tracking, advertising, analytics, or remote data collection.

---

## 2. Summary

BOLT1 does **not** collect, sell, share, or transmit personal information to the publisher or to any external server.

The application may store certain user-created workspace data locally on the user's device, such as:

- workspace or project names created by the user;
- web page URLs added by the user;
- display names or titles assigned by the user;
- selected desktop application paths or shortcuts;
- local application launcher items;
- language or interface preferences;
- basic local configuration required for the app to function.

This information is stored locally on the user's own device and is used only to provide the core functionality of the application.

## 4. Local Data Used by the App

BOLT1 allows users to manually add and manage web pages and desktop applications. In order to provide this functionality, the app may save the following information locally:

### 4.1 Web Page Records

When the user adds a web page, BOLT1 may store:

- the URL entered by the user;
- the title or display name of the web page;
- the type of item, such as `web`;
- the creation date of the item;
- the workspace or project where the item belongs.

This information is used only to display the saved web item inside the application and to open it later in the user's default web browser.

### 4.2 Desktop Application Records

When the user adds a desktop application, BOLT1 may store:

- the selected application path;
- the selected shortcut path;
- the application display name;
- the type of item, such as `app`;
- the workspace or project where the item belongs;
- optional icon or visual category information used for display.

This information is used only to show the application inside BOLT1 and to launch it later when the user chooses to run it.

### 4.3 Workspace and Project Data

BOLT1 supports project-based workspaces. For this reason, the app may store:

- project names;
- project identifiers;
- the currently active project;
- the list of launcher items inside each project.

This data allows the user to organize different work contexts and launch the correct set of web pages and desktop applications for each project.

### 4.4 User Preferences

The app may store simple local preferences, such as:

- selected language;
- interface preferences;
- active workspace information;
- basic app settings.

These preferences are used only to improve the user experience and keep the app state consistent when it is reopened.

## 5. Local Storage

BOLT1 stores its data locally on the user's device.

The application may use local storage technologies such as Hive or other local app storage mechanisms to save workspace data and launcher items.

This local data is not uploaded to the publisher, not shared with third parties, and not transmitted to an external server by BOLT1.

The user remains in control of the data stored inside the application.

---

## 6. Application Discovery and System Interaction

BOLT1 may include functionality that helps the user select desktop applications from the operating system.

Depending on the platform and app version, BOLT1 may read local shortcut or application information from locations such as:

- Start Menu shortcuts;
- Desktop shortcuts;
- selected executable files;
- selected application paths;
- Linux desktop entry files, where applicable.

This process is used only to help the user choose applications to add to their workspace.

BOLT1 does not upload the list of installed applications to any server. The discovery and selection process is performed locally on the user's device.

---

## 7. Launching Web Pages and Applications

When the user chooses to launch saved items, BOLT1 may ask the operating system to open:

- saved web URLs in the default browser;
- selected desktop applications;
- selected shortcuts or executable files.

This action is performed through the operating system's normal launching behavior.

For web items, the user's default browser may connect to the website that the user saved. BOLT1 is not responsible for the privacy practices of third-party websites opened by the user.

For application items, the launched desktop application may have its own privacy policy and data practices. BOLT1 does not control third-party applications launched by the user.

---

## 8. Internet Access

BOLT1 itself does not use internet access to collect analytics, transmit personal data, display advertisements, or synchronize user data.

However, when the user saves and launches a web page, the user's default browser will open that website. Any information exchanged with that website is handled by the browser and the website itself, not by BOLT1.

Users should review the privacy policies of any websites they choose to open through BOLT1.

## 11. Data Retention

Data saved in BOLT1 remains stored locally on the user's device until the user deletes it.

Users can remove saved items from inside the application by deleting web or application records.

Depending on the operating system, uninstalling the application or clearing the application data may also remove locally stored BOLT1 data.

---

## 12. User Control and Deletion

Users can control their data by:

- deleting saved web page records;
- deleting saved application records;
- removing workspace items;
- uninstalling the application;
- clearing the app's local storage from the operating system, where supported.

Because BOLT1 does not store user data on remote servers, the publisher cannot remotely access, recover, edit, or delete data stored locally on the user's device.

BOLT1 does not provide encryption for all local user-created launcher data unless such functionality is explicitly added in a future version.
